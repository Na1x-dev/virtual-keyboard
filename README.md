## ✨ Особенности

* 🚀 **Vanilla JS:** Написано без тяжелых фреймворков и внешних зависимостей.
* ⚡ **User Experience:** Мягкие анимации нажатия клавиш и мгновенный визуальный отклик.
* 🌐 **Ready to Use:** Готовый UI-компонент, который легко интегрировать в терминалы, веб-киоски или CRM-системы.
* 🛠 **Clean Code:** Понятная и модульная структура кода, открытая для быстрой кастомизации.

---

## 🛠 Стек технологий

Проект построен с использованием базового веб-стека, что гарантирует максимальную скорость работы и совместимость:

* **HTML5** — Семантическая разметка элементов ввода и интерфейса.
* **CSS3** — Flexbox/Grid разметка, кастомные переменные для тем и плавные переходы (`transitions`).
* **JavaScript (ES6+)** — Логика переключения регистров, симуляция ввода и обработка событий мыши/тач-скрина.

## 📦 Быстрый старт

Проект не требует сборщиков (Webpack/Vite) или установки пакетов через `npm`.

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Na1x-dev/virtual-keyboard
   ```

2. **Перейдите в папку проекта:**
   ```bash
   cd virtual-keyboard
   ```

3. **Запустите проект:**
   * Просто дважды кликните по файлу `index.html`, чтобы открыть его в браузере.
   * Или используйте расширение **Live Server** в VS Code для локального веб-сервера.

## 🔧 Кастомизация

Вы можете легко изменить цветовую гамму или размеры клавиш. Для этого откройте файл `style.css` и отредактируйте корневые стили или классы кнопок. Код снабжен логичными названиями классов, что упрощает внедрение ваших собственных тем оформления.
